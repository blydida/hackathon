# UX Hunter

Лендинг внутреннего продуктового хакатона **UX Hunter** для Jobescape (веб + iOS).

Команды берут продукт, находят баги и предлагают продуктовые улучшения по двум обязательным стримам — кор-функционал и количество багов.

**Живая версия:** https://uxhunter.vercel.app

## Стек

- Один файл `index.html` — вёрстка, стили и скрипты внутри, без сборки
- [Supabase](https://supabase.com) — регистрация команд и живой список в реальном времени (Postgres + Realtime)
- Задеплоено на [Vercel](https://vercel.com)

## Деплой

Статический файл, деплоится как есть — просто скопировать `index.html` в любой статический хостинг.
